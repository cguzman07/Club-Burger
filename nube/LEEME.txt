Club Burger · Nube (Supabase + Netlify)
========================================

La caja sigue en el computador (Club Burger.exe + datos_pos.db).
Supabase guarda una copia en internet. Netlify es la web del dueño
para entrar desde cualquier lugar.

1) Supabase
   - Crea un proyecto en https://supabase.com
   - SQL Editor → pega y ejecuta: nube/supabase/schema.sql
   - Authentication → Users → Add user
     (correo y contraseña del dueño; confirma el email o desactiva
     "Confirm email" en Authentication → Providers → Email)
   - Settings → API:
       Project URL          → SUPABASE_URL
       anon public          → SUPABASE_ANON_KEY   (Netlify)
       service_role secret  → SUPABASE_SERVICE_KEY (solo el PC)

2) Computador del restaurante
   - Abre local.env en la raíz del proyecto (Club Burger/local.env)
   - Pega SUPABASE_URL y SUPABASE_SERVICE_KEY
   - Cuando tengas la web: PANEL_PUBLICO_URL=https://tu-sitio.netlify.app
   - Abre "Iniciar Panel Dueño.bat" y déjalo abierto
   - En la consola debe decir: Nube: conectada

3) Netlify
   - Sube este proyecto a GitHub (o arrastra la carpeta nube/web)
   - New site from Git → este repositorio
   - Build: ya está en netlify.toml (publica nube/web)
   - Site settings → Environment variables:
       SUPABASE_URL
       SUPABASE_ANON_KEY
   - Deploy
   - El dueño entra a esa URL con el correo del paso 1

4) Uso diario
   PC: Club Burger.exe (cajeros, usuarios, caja, inventario)
       + Iniciar Panel Dueño.bat (sube datos e imprime pedidos)
   Celular en el local: QR + PIN (igual que ahora)
   Celular desde cualquier parte: web de Netlify + correo del dueño

Si se cae internet, el mostrador sigue vendiendo. Al volver, se sincroniza.
El ticket remoto solo sale si el PC está encendido con el panel.
